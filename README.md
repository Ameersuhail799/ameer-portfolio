A high-performance, ultra-sleek personal portfolio web application built with **Next.js 14 (App Router)**, **TypeScript**, **Framer Motion**, and **Tailwind CSS**. Designed for high-impact recruiter storytelling, product demonstrations, and showcasing engineering capabilities.

---

## ✨ Key Features & Architectural Innovations

- 🪄 **"UNFOLD" Intro Experience**: An automated, 3.2-second 4-scene transition that folds and crystallizes wireframe bounds directly into the live Hero section layout.
- 🌿 **Interactive Git Commit Tree**: A developer-first career journey log styled like a GitHub branch commit tree (`main`, `feat/ai-ml`, `feat/apps`, `release/vision`).
- ⚡ **Interactive Kinetic Grid**: Real-time cursor attraction mesh background layered behind glassmorphism cards.
- 🏆 **Flagship Product Showcase**: Full product breakdowns for flagship projects like **CareerOS** (AI Student Placement Suite), **KTU Activity Point Manager**, **BunkBuddy**, and **Property ML Predictor**.
- 📱 **100% Mobile & Viewport Responsive**: Engineered for desktop, tablet, and mobile browsers with zero horizontal overflow.

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ameersuhail799/ameer-portfolio.git
   cd ameer-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).

5. **Build for production**:
   ```bash
   npm run build
   ```
